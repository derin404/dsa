# Expression Evaluation Using Expression Tree and Stack

## 📌 Overview

This project implements and analyzes two approaches for evaluating a postfix arithmetic expression:

1. Expression Tree Construction and Evaluation
2. Stack-Based Postfix Evaluation

The project compares both approaches based on their implementation, operations,
data structures, time complexity, space complexity, and structural information.

---

## 🎯 Objective

The objectives of this assignment are:

- To construct an Expression Tree from a postfix expression.
- To evaluate the expression using the Expression Tree.
- To evaluate the same expression using a stack-based approach.
- To trace the intermediate evaluation steps.
- To compare both approaches based on performance and memory requirements.
- To analyze their time and space complexities.
- To identify the suitable approach for different applications.
